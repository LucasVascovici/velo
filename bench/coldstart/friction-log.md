# Friction log

Template. One row per event the agent hit; copy this file to
`friction-log-<tag>.md` for each run. Empty until the owner runs the protocol
in [`README.md`](README.md); nothing below is a result.

Run: release tag `____`, date `____`, agent `____`.

Kind is one of `guess` (the agent had to guess at something the docs did not
say), `error` (a command or call failed) or `missing method` (it reached for a
method, flag or tool that does not exist).

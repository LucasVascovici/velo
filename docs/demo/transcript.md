# Demo: an agent run went wrong

This transcript is generated by [`demo.sh`](demo.sh) and checked in CI, so it
is always what the current `velo` prints. Ids and times are replaced by
fixed text; see the [README](./).

## A human saves the base

```console
$ velo init
✔ Initialized empty Velo repository in /tmp/demo/repo/.velo
  Default .veloignore written. Branch: main
```

```console
$ velo save "Base: total and average"
✔ Saved <snap-1> on main  (3 new, 0 modified, 0 deleted)
```

## Recovery

Undo removes the bad snapshot and puts the tree back. The earlier calls stay.

```console
$ velo undo
✔ Removed snapshot <snap-4> — "run-7 call 3: tidy up average"
  Working files rewound to <snap-3>
  Bring it back with velo redo
```

```console
$ velo history

History for branch: main
  Hash               Branch               Date                  Message
────────────────────────────────────────────────────────────────────────────────────────────────────
→ <snap-3>   main                 2025-01-06 09:00   run-7 call 2: add largest (HEAD → main)
  <snap-2>   main                 2025-01-06 09:00   run-7 call 1: add a one-element test
  <snap-1>   main                 2025-01-06 09:00   Base: total and average
────────────────────────────────────────────────────────────────────────────────────────────────────

```

```console
$ velo status
Branch: main  Position: <snap-3>  "run-7 call 2: add largest"
  Working directory clean.
```
